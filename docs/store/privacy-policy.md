# Privacy policy for the Microsoft Store

The Store's **Privacy policy** field needs a public web address. The policy is the project's [privacy statement](../privacy.md); there is one source of truth, so this page does not repeat it.

* **Where to publish it:** the rendered [docs/privacy.md](../privacy.md) in the public repository, for example `https://github.com/mjtpena/mikeshift/blob/main/docs/privacy.md`, or the same page on GitHub Pages if you want a cleaner address.
* **When to update it:** before any release that changes what the app does with data (for example a feature that needs the network). Change the date at the top of the statement, and mention it in the [changelog](../../CHANGELOG.md).
* **What it covers:** that MikeShift has no network code, account or telemetry; what the right-click entry, the drag gesture and the keyboard shortcut can see; what is stored on the PC and where; the optional Microsoft Word feature (off by default, and Word itself may connect to Microsoft); and how to delete everything.
